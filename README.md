## Solution

problem: lots tons of documents. Maybe someone knows what is going on when working with the client but if they leave EVERYONE is cooked!!! We need a twin to guide newcomers onboard.
For this we build on microsoft copilot: using sharepoint, teams, outlook, etc. to create dedicated a dedicated digital secretary for each client. For when people need clarification, the secretary asks for info throughout the lifetime, not only when info is needed. This tackles the problem before it occurs. Humans are forgetful and always busy. This solution simplifies administration and knowledge retention.

Client detection is based on UPN
Finetuned for payroll; focused on getting the core produce of SDWorks right.

For each tag or knowledge tag is a time tag.
